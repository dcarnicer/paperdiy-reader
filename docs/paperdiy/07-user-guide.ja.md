# 07 — ユーザーガイド（PaperDIY）

**言語：** [Español](07-user-guide.md) · [English](07-user-guide.en.md) · [简体中文](07-user-guide.zh-CN.md) · **日本語**

このガイドはファームウェアを書き込み済みであることを前提としています。
まだの場合は [README](../../README.ja.md) と `06-porting.md` を参照して
ください。

## 初回起動

1. `.epub` を SD カード（FAT32 または exFAT）にコピーします。フォルダも
   使えます。
2. SD カードを挿入します。
3. 電源ボタンを短押しして起動します。
4. 最初の画面はライブラリ/ホームです。A/B で移動、B 長押しで決定、A 長押し
   で戻ります。

初めて本を開くときは `/.crosspoint/` にキャッシュを生成します（数秒かかり
ます）。2 回目以降は速くなります。

## 操作

| 操作 | 動作 |
|---|---|
| A 短押し | 上 / 前ページ |
| B 短押し | 下 / 次ページ |
| A 長押し | 戻る / 終了 |
| B 長押し | 決定 / 選択 |
| A+B | 電源（メニュー/スリープ） |
| 電源クリック | 電源オン。起動中は設定された動作（既定はスリープ/電源オフ） |
| 電源ダブルクリック | 電源オフ（PM1 で有効な場合のハードウェア電源オフ） |
| 電源約 10 秒 | ダウンロードモード（赤 LED、画面が固まることがあります） |

電源クリックは出荷時のリセットではなくなり、PM1 がクリックをファームウェア
へ渡します。元の動作にしたい場合は
`-DPAPERDIY_PM1_APP_POWER_BUTTON=0` でビルドし、A+B でスリープします。

リーダーでは A/B でページを送ります。リストでは選択を移動し、B 長押しで
項目を開き、A 長押しで戻ります。

短押しは押した時ではなく**離した時**に登録されます。2 ボタンだけでクリック
と長押しを区別するための仕組みです。「押した瞬間にページ送り」に変えると、
長押しがメニューを開く前にページ送り/移動を発火する可能性があります。UX の
トレードオフとして未決定です。

## ライブラリ

- ホームには最近読んだ本/表紙が表示されます。ファイルブラウザでフォルダに
  入れます。
- 本の上で B 長押しするとメニューが開きます（開く、詳細、削除など）。
- メタデータと表紙は `/.crosspoint/` にキャッシュされます。おかしくなった
  場合は、このフォルダを削除すると再生成されます。

## 読書

- B 長押しでリーダーメニューが開きます：目次、ブックマーク、ハイライト、
  辞書、% ジャンプ、文字設定、画面の向きなど。
- A 長押しで前のメニューに戻ります。
- 読書位置は自動保存されます。
- ハイライト/切り抜きは SD カードに保存されます（リーダーメニュー参照）。

## 漫画

- ファームウェアは `.cbz`/`.cbr` を直接開けません。EPUB に変換してください。
- 推奨: `scripts/comic_to_epub.py`。画像ごとに 1 つの XHTML ページを生成し
  ます（A/B でページ送り可能）。CBZ/ZIP または PDF に対応:

  ```sh
  python3 scripts/comic_to_epub.py tome.cbz tome.epub
  python3 scripts/comic_to_epub.py tome.pdf tome.epub --title "第1巻" --author "著者"
  ```

  PDF には `pdftoppm` が必要です（macOS では `brew install poppler`）。
- Calibre でも可能です: CBZ を追加して EPUB に変換すると、画像ごとに
  1 ページ生成されます。
- EPUB を SD カードの `/Comics/` にコピーします。初回オープン時は索引を
  作成するため数十秒かかり、その間ボタンは効きません。
- EPUB は画像 1 枚につき XHTML 1 ページである必要があります。単一 HTML の
  PDF-reflow EPUB（または Calibre プラグインの最適化後）は `1/1` のまま
  ページ送りできないことがあります。
- メニューに `章: 1/1 ページ` と表示されるのは、各ページが独立した文書だか
  らです。実際の進捗は `ページ N`/`ブック: %` で確認します。

## フォント

- `.ttf`、`.otf`、`.ttc` を SD カードの `/fonts/` または `/.fonts/` に
  コピーします。
- 同じフォントファミリーをサブフォルダにまとめられます。
- 読書設定でフォントを選択します。レギュラー/ボールド/イタリックは
  ファミリー単位で対応付けられます。
- 辞書の IPA には、そのグリフを含むフォントが必要です。

## 辞書

- 各 StarDict 辞書を `/dictionaries/<名前>/`（または
  `/.dictionaries/`）にコピーします。未圧縮の `.idx` と
  `.dict`/`.dict.dz` が必要です。
- **Settings → Reader → Dictionary** で辞書を選択します。
- 初回の検索で索引を生成します（`.qidx`/`.sidx`）。以降は高速です。
- スペイン語なら Wiktionary/RAE/WikDict の StarDict を試してください。

## Wi-Fi、Calibre、OPDS、Web UI

- **Settings → Network**：Wi-Fi（2.4 GHz）をスキャン/接続します。
- **Web UI**：画面にアドレスが表示されます。ブラウザから本のアップロード、
  ファイル表示、設定変更、更新ができます。
- **Calibre**：Calibre で「Connect to wireless device」を使います。リーダー
  に手順が表示されます。
- **OPDS**：カタログ（Project Gutenberg、Standard Ebooks など）を追加し、
  リーダーから閲覧します。
- **KOReader Sync**：認証情報を設定して進捗を同期します。
- **OTA**：設定から更新を確認できます。USB で書き込むこともできます。

## 電源とスリープ

- リーダーは無操作タイムアウト後に自動でスリープします。
- 手動でスリープするには、A+B を長押しするか電源を押します（設定された
  動作によります）。
- バッテリー駆動時は、スリープ時に PM1 へ**電源オフ**を要求します。電源が
  切れ、クリックで再びオンになります（ページはパネルに残ります）。
- USB 接続時も PM1 が電源を切る場合があり、その場合は電源ボタンでのみ
  再起動できます。**ディープスリープ**のフォールバックと A/B 復帰は、
  USB が基板を維持している場合だけです。
- 長期間使わない場合は、ダブルクリックで電源を切ってください。
- バッテリーは 140 mAh です。駆動時間はスリープにかかっています。Wi-Fi を
  オンにしたまま読むと大幅に短くなります。

## SD カード：推奨構成

```
/
├── Books/                 # EPUB（フォルダも使えます）
├── Comics/                # EPUB に変換した漫画
├── fonts/                 # TTF/OTF
├── dictionaries/          # StarDict を辞書ごとに 1 フォルダ
└── .crosspoint/           # リーダーキャッシュ（リセット時以外は触らない）
```

## よくある問題

| 症状 | 試すこと |
|---|---|
| 画面が白い | PM1 GPIO2/GPIO46？DCDC？完全書き込み？ |
| 画像が反転している | `paperdiyLgfxConfig` の `rotation` を変更（0 ↔ 2） |
| ページ送りで残像が出る | 設定 > 表示 で `Refresh Frequency` を 5、次に 1 を試す。新しい高速 LUT は検証中 |
| SD がマウントされない | FAT32/exFAT、接触、別のカードを試す。起動時にカードがない場合は、挿入すると再起動します |
| ページが送れない | バッテリー？A/B？スリープ中ではないか？ |
| 復帰しない | ボタンは正常か？`ext1` GPIO3/4？ |
| バッテリー表示がおかしい | `About > Battery`（VBAT/状態）や `[PWR] Battery:` ログを確認。セル交換時は再キャリブレーション |
| Wi-Fi につながらない | 2.4 GHz、パスワード、AP アイソレーション。スマートフォンのテザリングを試す |
| 本が開かない | EPUB が有効か、サイズ、RAM。本のキャッシュを削除 |
| 更新後に UI がおかしい | `/.crosspoint/` を削除して再起動 |

## 復旧

問題が起きた場合：

1. 電源を約 10 秒長押しして赤 LED が点灯 → ダウンロードモード。
2. `firmware.factory.bin` を `0x0` に書き込みます。
3. ダウンロードモードに入らない場合は、別のケーブル/USB ポートを試して
   ください。ESP32-S3 のネイティブ USB にアダプターは不要です。

実験する前に、必ず元のファームウェアのバックアップを取ってください。
